# ELN 2025 variant list

Source: Apperley JF et al., *2025 European LeukemiaNet recommendations for the
management of chronic myeloid leukemia*. Leukemia 39, 1797–1813 (2025).
Table 5, page 1802. https://doi.org/10.1038/s41375-025-02664-w

Licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

Adaptation: grouped protein substitutions expanded to 29 individual rows;
amino acids displayed with three-letter names. The transcript column identifies
DRAGEN's reporting reference NM_005157.6; it is not a transcript assignment made
by Table 5. TKI entries retain the table's wording. Scope is CML.

Import `ELN_2025_Tabell5.xlsx` under Settings. Matching highlights the protein
substitution in the current reporting reference; it does not select rows for
lookup/export, merge variants or classify compound alleles.
